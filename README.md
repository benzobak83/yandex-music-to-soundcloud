# Перенос треков из Яндекс Музыки в SoundCloud

Скрипт переносит понравившиеся треки из коллекции «Мне нравится» в Саундклауд. Он находит совпадения в SoundCloud и ставит им лайки.

Нужны **Windows или macOS**, **Node.js 22.12+** и **Google Chrome**. Откройте Chrome с вашим обычным профилем.

**Настройка один раз**

- **macOS** — в Chrome включите **Вид → Разработчик → Разрешить JavaScript из событий Apple**.
- **Windows** — в Chrome 144+ откройте `chrome://inspect/#remote-debugging` и включите удалённую отладку. При подключении подтвердите запрос Chrome.

**Запуск из папки проекта**

1. `npm ci` — установить зависимости.
2. `npm run export` — в открывшейся вкладке выберите **Коллекция → Мне нравится** (**My Collection → My Favorites**), оставьте фильтр **Все / All** и нажмите Enter в терминале.
3. `npm run import` — перенести лайки. Если SoundCloud попросит войти или пройти проверку, сделайте это в рабочей вкладке и нажмите Enter в терминале.

Повторный импорт пропускает обработанные треки.

Чтобы сбросить статусы всех обработанных треков, выполните `npm run import -- --clear-status all`. Затем запустите `npm run import` для повторной проверки. Лайки в SoundCloud сохранятся.
